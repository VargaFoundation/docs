API overview

Everything the console does goes through the REST API, under /api/v1 on your instance. The REST API guide walks through a first script; this page is the map.

The OpenAPI document​

The API is described by an OpenAPI 3 document, the contract the console and the CLI are generated against: packages/contracts/openapi.yaml. Take the version of your instance (GET /api/v1/edition says which). The MCP and A2A doors are not in it: they speak their own protocols (MCP, A2A).

Conventions​

Base path/api/v1
AuthenticationAuthorization: Bearer chg_…, a token of scope * (REST guide); the console uses a session cookie
A project in a pathits UUID, org:slug, org/slug, or a bare slug when it is unique
A work item in a pathits UUID or its key (BIL-12)
Lists?cursor=…&limit=… (1 to 200, 50 by default); the answer is {"items": [...], "meta": {"next_cursor", "has_more"}}
ErrorsRFC 9457 problems (Error codes)
Concurrent changessend the version you read (base_version, base_revision); a 409 stale_base says someone changed it first
Request idsevery answer carries X-Request-Id
Unknown keysrefused (422): a typo does not pass silently

Rate limits​

Authenticated REST calls are not rate-limited by the API. Sign-in and webhook routes are limited per client address (600 a minute by default, 429 with Retry-After). The MCP and A2A doors have their own limits (120 calls a minute per token).
